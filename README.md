# Smart Daily Standup Bot

Smart Daily Standup Bot is a full-stack AI web app that converts rough daily standup notes into a clean Agile summary with **Completed**, **Planned**, and **Blockers** sections.

## Features

- Manual daily standup input
- AI-generated clean summary using Gemini AI
- Save standups to PostgreSQL
- View saved standups in history feed
- Search previous standups
- Delete saved standups
- GitHub activity-based standup generation
- MCP-inspired GitHub tool runner
- Dark mode UI

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- PostgreSQL
- Gemini AI API
- GitHub API
